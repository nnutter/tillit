# CLI

## Skills

Load the skills named in ancestor `AGENTS.md` files before working here.

Also load these skills for this package:

- `go-cli` when creating the command-line application, adding subcommands, or wiring the CLI to the daemon.
- `go-cobra` when building commands with Cobra.
- `go-fang` when using Fang as the Cobra execution entry point.
- `go-pflags` when defining flags with pflag.
